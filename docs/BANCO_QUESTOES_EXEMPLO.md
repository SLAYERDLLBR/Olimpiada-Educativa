# 🚀 COMO USAR ESTE BANCO

### Passo 1: Usar Como Template
Copie uma questão completa (todas as 7 modalidades) e adapte:
- Mude os números
- Mude o contexto
- Mude os nomes dos personagens

### Passo 2: Expandir para +200 Questões
Você precisa de:
- 20 competências × 5 = 100 competências (varie séries)
- 100 × 7 formatos = 700 questões total
- Estimar: 2 horas por competência = 200 horas (viável com AI)

### Passo 3: Validação Pedagógica
Cada questão deve passar por:
1. **Alinhamento BNCC**: Está na série/nível correto?
2. **Bloom Check**: Está no nível cognitivo certo?
3. **Teste com Crianças**: Conseguem responder?
4. **Feedback Loop**: Ajuste dificuldade

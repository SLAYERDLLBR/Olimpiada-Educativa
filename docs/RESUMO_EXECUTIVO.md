## 🎮 OS 7 FORMATOS DE QUESTÃO

Cada competência pedagógica é testada **7 formas diferentes**:

```
1️⃣ MÚLTIPLA ESCOLHA        → Reconhecimento rápido
2️⃣ VERDADEIRO/FALSO        → Decisão binária
3️⃣ MATCHING (Drag-Drop)    → Associação conceitual
4️⃣ PREENCHA O BRANCO       → Produção de resposta
5️⃣ CLIQUE VISUAL           → Reação rápida visual
6️⃣ ENTRADA NUMÉRICA        → Cálculo direto
7️⃣ SEQUÊNCIA/ORDENAÇÃO     → Lógica de padrões
```

**Por quê?** Crianças têm múltiplas inteligências. Alguns acham fácil Múltipla Escolha mas travam em Sequência. Outros adoram Desenho Visual mas dormem em Verdadeiro/Falso. Com 7 formatos, **todos têm chance de brilhar**.

## ⏱️ SISTEMA DE TIMING (O Diferencial)

### Regra Simples, Efeito Poderoso:

```
QUESTÃO APARECE
    ↓
[0-15s] SPEEDRUN ZONE 🔥
├─ Primeira a responder: Pode ganhar +150% de pontos
├─ Bônus extra: +50 pts automáticos para todos (se todos nessa faixa)
└─ Efeito visual: Confete, efeitos épicos

[15-30s] EARLY ADVANCE ZONE ⚡
├─ Se TODAS as 7 equipes responderam: AVANÇA IMEDIATAMENTE
├─ Não espera mais 10s
├─ Bônus: +25 pts (todos ganharam velocidade)
└─ Feedback: "🟢 SPEEDRUN CONSEGUIDO!"

[30-40s] NORMAL ZONE ⏱️
├─ Equipes lentas podem ainda responder
├─ Aguarda as últimas antes de passar
└─ Sem pressa, sem penalidade

[40s+] TIMEOUT 🔴
├─ Gong sonoro, último pisca vermelho
├─ Equipes que não responderam: 0 pts (sem punição, apenas perda)
├─ Avança MESMO ASSIM
└─ Próxima questão é oportunidade de recuperação
```

**Resultado:** Engajamento constante, sem "vou esperar os 40s". Crianças querem ser rápidas porque rápido = legal, não porque obedecem ordem.

## 🧮 EXEMPLO REAL: Adição até 20 (1º-2º ano)

### Mesma competência, 7 formas diferentes:

**Formato 1: Múltipla Escolha**
```
Quanto é 7 + 5?
[A] 10  [B] 11  [C] 12 ✓  [D] 13
Pontos: 100 | Tempo: 40s | Dificuldade: ⭐
```

**Formato 2: Entrada Numérica**
```
Complete: 7 + ? = 12
[_____]
Resposta: 5
Pontos: 130 | Dificuldade: ⭐⭐
```

**Formato 3: Clique Visual**
```
Quantas bolinhas no total?
🟢🟢🟢🟢🟢🟢🟢 + 🟢🟢🟢🟢🟢 = ?
[10] [11] [12] ✓ [13]
Pontos: 100 | Dificuldade: ⭐
```

**Formato 4: Preencha o Branco**
```
"Se tenho 7 maçãs e ganho 5, fico com ____ maçãs"
[_____]
Resposta: 12
Pontos: 140 | Dificuldade: ⭐⭐
```

**Formato 5: Verdadeiro/Falso**
```
"7 + 5 = 12"
[VERDADEIRO] ✓
[FALSO]
Pontos: 80 | Dificuldade: ⭐⭐ (pegadinha!)
```

**Formato 6: Drag & Drop**
```
Conecte operação a resultado:
5 + 3 ↔ 8 ✓
7 + 2 ↔ 9 ✓
2 + 6 ↔ 8 ✓
Pontos: 120 | Dificuldade: ⭐⭐
```

**Formato 7: Sequência**
```
Ordene do menor para o maior:
12, 5, 7, 3, 10
Ordem: 3 → 5 → 7 → 10 → 12 ✓
Pontos: 120 | Dificuldade: ⭐⭐
```

**Resultado:** Mesma competência "adição até 20", testada de 7 jeitos. Criança que acha Múltipla Escolha fácil mas Sequência difícil aprofunda compreensão. Criança que acha Clique Visual mais fácil que Numérica também ganha.

## 🏆 SISTEMA DE PONTUAÇÃO DINÂMICO

### Fórmula Épica de Pontos:

```
PontosFinais = (PontosBrutos × VelocidadeMultip × ComboMultip) + BônusSincron

Onde:
├─ PontosBrutos = 80-160 (varia por formato)
├─ VelocidadeMultip:
│  ├─ <15s: ×1.5
│  ├─ 15-25s: ×1.2
│  └─ >25s: ×1.0
├─ ComboMultip:
│  ├─ 2 acertos: ×1.1
│  ├─ 3 acertos: ×1.2
│  └─ 4+ acertos: ×1.3
└─ BônusSincron:
   ├─ Todas responderam <30s: +50 pts
   └─ Todas responderam <40s: +25 pts
```

### Exemplo Real:

```
Equipe "Gênios da Matemática" responde:
├─ Formato: Numeric Input (base 140 pts)
├─ Tempo: 12s (multiplicador 1.5x)
├─ Combo: 3 acertos seguidos (multiplicador 1.2x)
├─ Todas responderam: +50 pts

Cálculo:
(140 × 1.5 × 1.2) + 50
= (140 × 1.8) + 50
= 252 + 50
= 302 PONTOS! 🎉

Placar atualiza ao vivo: +302 ⬆️
```

**Resultado:** Pontos são variáveis, dinâmicos, emocionantes. Não é sempre 100pts. Crianças veem o número subir ALTO e ficam animadas.

## 🎯 ESTRUTURA DE EQUIPES

### Balanceamento Automático:

```
28 JOGADORES → DISTRIBUIÇÃO INTELIGENTE

Cenário 1: 7 crianças do 1º, 21 de 3º-5º
Resultado: Cada equipe tem 1 aluno de 1º + 3 de série mais avançada
→ Ninguém fica sozinho, ninguém fica pra trás

Cenário 2: Mistura balanceada de séries
Resultado: Algoritmo distribui por série para evitar
→ Equipe só de 1º: Questões de 1º são fácil, logo desestimula
→ Equipe só de 5º: Questões de 1º são chato, logo aborrecimento

Mecânica: Score por EQUIPE, não individual
├─ Todos ganham pontos quando acertam
├─ Um "herói" não pode carregar sozinho
├─ Colaboração é natural, não forçada
└─ Vitória compartilhada é mais legal
```

## 🎨 EXPERIÊNCIA VISUAL

### Paleta & Estética:
```
Cores Primárias: Azul (#0066FF) + Amarelo (#FFD700)
Cores de Sucesso: Verde (#22C55E)
Cores de Atenção: Laranja (#FF8C00)
Cores de Erro: Vermelho (#EF4444)

Tipografia:
- Headings: Fredoka One ou Baloo 2 (divertida, juvenil)
- Corpo: Poppins ou Inter (moderna, legível)

Animações:
- 300-500ms (crianças conseguem acompanhar)
- Feedback imediato (acerto verde + som alegre)
- Transições suaves (não assustam)

Layout:
- Responsivo (mobile, tablet, desktop)
- Cards com sombra
- Placar animado em tempo real
```

### Momentos "WOW":

```
1️⃣ Quando alguém responde antes de 15s:
   ✓ Check animado
   → Pontos fluem com animação upward
   → Nome da equipe destaca no ranking
   → Efeito "spark"

2️⃣ Quando TODAS respondem <30s:
   🔥 Tela BRILHA OURO
   → Confete cai
   → Som épico (chime)
   → "+50 BÔNUS SPEEDRUN!" em letras grandes

3️⃣ No timeout:
   🔴 Barra fica vermelha piscando
   → Beep acelerando ("5... 4... 3...")
   → Gong sonoro
   → Transição suave (sem drama)

4️⃣ Resultado final:
   🏆 TELA INTEIRA com ranking
   → Medalhas animadas (1º-3º)
   → Confete infinito
   → Cada equipe pode "acenar"
```

## 💻 TECH STACK (Recomendado)

### Frontend:
```
React 18 + TypeScript
├─ Zustand (state management)
├─ Tailwind CSS (styling)
├─ shadcn/ui (components)
├─ Framer Motion (animações épicas)
├─ Socket.IO client (realtime)
└─ Konva.js (canvas, se tiver drawing)
```

### Backend:
```
Node.js + Express/Fastify
├─ Socket.IO (28 jogadores simultâneos)
├─ Supabase PostgreSQL (users, stats, leaderboard)
├─ Redis (placar em memória, ultra-rápido)
└─ Sentry (error tracking)
```

### Deploy:
```
Frontend: Vercel (free, fast)
Backend: Railway ou Render (affordable, confiável)
Database: Supabase (PostgreSQL, free tier)
Realtime: Socket.IO (funciona em Railway/Render)
```

## 🎯 MÉTRICAS DE SUCESSO

```
✅ Engajamento
├─ Objetivo: 80%+ das crianças pedem "mais uma rodada"
├─ Métrica: Tempo médio de sessão >15min
└─ Target: NPS >80 (Net Promoter Score)

✅ Aprendizado
├─ Objetivo: +15% improvement em avaliações formais pós-uso
├─ Métrica: Taxa de acerto por competência (tracking)
└─ Target: Padrão de melhora consistente

✅ Inclusão
├─ Objetivo: Alunos com dificuldade também ganham
├─ Métrica: Distribuição de vitórias (não sempre os mesmos)
└─ Target: Top 3 mudam a cada sessão em 60%+ dos casos

✅ Performance
├─ Objetivo: Sem lag ou crash
├─ Métrica: Latência <100ms, Uptime 99.5%
└─ Target: Escalável para 1000+ sessões simultâneas

✅ Acessibilidade
├─ Objetivo: WCAG AA compliant
├─ Métrica: Suporte a leitores de tela
└─ Target: Usável por crianças neurodiversas
```

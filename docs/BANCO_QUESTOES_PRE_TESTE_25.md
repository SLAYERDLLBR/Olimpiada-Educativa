# 📥 COMO USAR ESTE BANCO

## 1. Selecionar Questão Aleatória:
```typescript
const getRandomQuestion = (serie: number, subject: 'PT' | 'MAT') => {
  const allQuestions = QUESTION_BANK[serie][subject];
  return allQuestions[Math.floor(Math.random() * allQuestions.length)];
};
```

## 2. Categorias Específicas:
```typescript
const getByCategory = (serie: number, subject: 'PT' | 'MAT', category: string) => {
  return QUESTION_BANK[serie][subject].filter(q => q.category === category);
};
```

## 3. Por Dificuldade:
```typescript
const getByDifficulty = (serie: number, subject: 'PT' | 'MAT', difficulty: 1 | 2 | 3) => {
  return QUESTION_BANK[serie][subject].filter(q => q.difficulty === difficulty);
};
```
